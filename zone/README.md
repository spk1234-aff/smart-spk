# ระบบตรวจเขตพื้นที่และห้องเรียน (SMART SPK · zone)

ใช้สำหรับสภานักเรียนออกตรวจความสะอาด แบ่งเป็น 2 ประเภท บันทึกแยกกัน
- 🧹 **เขตพื้นที่**: เขตรับผิดชอบนอกอาคารของแต่ละห้อง
- 🏫 **ห้องเรียน**: ห้องเรียนประจำของแต่ละห้อง

ใช้ Firebase โปรเจกต์ `spk-score-system` และบัญชีผู้ใช้ชุดเดียวกับ SMART SPK

เว็บ: `https://spk1234-aff.github.io/smart-spk/zone/`

## ใครใช้อะไรได้บ้าง
| ผู้ใช้ | เห็น / ทำได้ |
|---|---|
| สภานักเรียน (role `council`) | ตรวจเขตพื้นที่/ห้องเรียน: กด **ผ่าน / ไม่ผ่าน** ถ้าไม่ผ่านต้องเลือกสาเหตุและถ่ายรูป · ดูแผนผัง |
| ครูที่ปรึกษา | **ห้องของฉัน**: ผลตรวจและรูปของห้องที่ปรึกษา (ทั้งสองประเภท) · รายงานรวม |
| แอดมิน / แอดมินกิจการ | รายงานรายวัน/สัปดาห์/เดือน/ภาคเรียน + อันดับห้อง · ส่งออก Excel / พิมพ์ PDF · **ไม่ผ่านซ้ำ → หักคะแนน** · ตั้งค่า |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)
1. **อัปโหลดไฟล์**: ใน repo `smart-spk` กด *Add file → Upload files* แล้วลากทั้ง **โฟลเดอร์ `zone`** ขึ้นไป → Commit
   ไฟล์ของ SMART SPK เดิมไม่ต้องแก้
2. **เพิ่มกฎ Firestore**: Firebase Console → Firestore Database → Rules
   - คัดลอกกฎเดิมเก็บไว้ก่อน
   - วางข้อความในไฟล์ `firestore-rules-zone.txt` ต่อจากบรรทัด `match /ss_behavior/{id} { ... }` และก่อนบรรทัด `// ---------------- spk-score-app`
   - กด **Publish**
3. **ตั้งค่าครั้งแรก**: ล็อกอินด้วยบัญชีผู้ดูแลระบบ SMART SPK แล้วเปิดเมนู **ตั้งค่า**
   - **เขตพื้นที่ / ห้องเรียน**: กด "ดึงจาก SMART SPK ทั้งหมด" ใส่เลขห้องเรียนประจำของแต่ละห้อง แล้วกด **บันทึก**
     ต้องกดบันทึกอย่างน้อย 1 ครั้ง สภาฯ จึงจะเห็นจำนวนห้องและเขตที่ถูกต้อง
   - **เกณฑ์ตรวจ / หักคะแนน**: แก้สาเหตุที่ไม่ผ่าน เกณฑ์ไม่ผ่านซ้ำ (ค่าเริ่มต้น 2 ครั้งใน 7 วัน) และคะแนนที่หัก (ค่าเริ่มต้น 5)
   - **บัญชีสภานักเรียน**: มีรายชื่อ 41 คนจากตารางลงเวลาใส่ไว้ให้แล้ว กด **สร้างบัญชี** แล้ว **ดาวน์โหลด Excel รหัสผ่าน** ทันที
     ระบบจะไม่แสดงรหัสผ่านซ้ำ
4. **เพิ่มลิงก์ในหน้า SMART SPK** (ถ้าต้องการ): เพิ่มลิงก์ `zone/` ในส่วนลิงก์/บริการของ SMART SPK

## การเชื่อมกับ SMART SPK
- **รายชื่อห้องและเขตพื้นที่**: อ่านจาก `ss_config/settings` (`rooms`, `areaByClass`) ถ้าผู้ดูแลระบบแก้เขตที่ระบบนี้ ระบบจะบันทึกกลับไปที่ SMART SPK ด้วย
- **ครูที่ปรึกษา**: ใช้ช่อง `homeroom` ในบัญชีครูของ SMART SPK
- **หักคะแนน**: เขียนข้อมูลแบบเดียวกับเมนูตัดคะแนนของ SMART SPK
  - `ss_behavior`: บันทึกรายการ (`k: "minus"`)
  - `ss_stu`: ปรับยอดรวมของนักเรียน
  - `students/{เลขประจำตัว}.khun`: ปรับคะแนนใน spk-score-app ถ้าเปิดการซิงก์ไว้
  - รายการที่หักจะแสดงในประวัติคะแนนของนักเรียนใน SMART SPK ตามปกติ และลบ/แก้ได้จากเมนูเดิม
- **เขตพื้นที่ที่ไม่ผ่านซ้ำ**: ระบบเลือกนักเรียนที่ครูบันทึก "✗ ไม่ลงเขต" (เมนูลงเขตพื้นที่ของ SMART SPK) ในวันที่ไม่ผ่านไว้ให้ก่อน กิจการฯ ตรวจทานและกดยืนยันเอง ระบบไม่หักอัตโนมัติ
- **ห้องเรียนที่ไม่ผ่านซ้ำ**: SMART SPK ยังไม่มีข้อมูลเวรห้องเรียน กิจการฯ จึงต้องเลือกนักเรียนเวรเอง

## ข้อมูลที่เก็บ (collection ใหม่)
| collection | เนื้อหา |
|---|---|
| `ss_zone_cfg/main` | ตั้งค่า: เขต/ห้องเรียนของแต่ละห้อง สาเหตุ เกณฑ์หักคะแนน |
| `ss_zone_chk/{วันที่}_{ชั้น-ห้อง}_{zone หรือ room}` | ผลตรวจ: 1 ห้อง/วัน/ประเภท = 1 เอกสาร ถ้าตรวจซ้ำจะทับของเดิม |
| `ss_zone_photo/…` (id เดียวกับผลตรวจ) | รูปหลักฐาน ย่อเหลือไม่เกิน ~90 KB |
| `ss_zone_ded/…` | ประวัติการดำเนินการ "ไม่ผ่านซ้ำ" (หัก/ไม่หัก) |

**โควตา (แพ็กเกจฟรี):** ตรวจวันละ 112 รายการ (56 ห้อง × 2 ประเภท) = เขียนประมาณ 150 ครั้ง/วัน ซึ่งน้อยมากเมื่อเทียบกับโควตา 20,000 ครั้ง/วัน
