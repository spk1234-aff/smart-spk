# SMART SPK

ระบบดูแลช่วยเหลือนักเรียน กลุ่มงานกิจการนักเรียน โรงเรียนโซ่พิสัยพิทยาคม
เว็บแอปแบบ PWA (ติดตั้งเป็นไอคอนบนมือถือได้) · ข้อมูลเก็บใน Firebase โปรเจกต์ `spk-score-system` (ใช้ร่วมกับ spk-score-app)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. ตั้งค่า Firebase (https://console.firebase.google.com → โปรเจกต์ spk-score-system)
1. **Authentication → Sign-in method** ตรวจว่าเปิด **Email/Password** แล้ว
2. **Firestore Database → Rules**
   - คัดลอกกฎเดิมเก็บไว้ก่อน (เผื่อย้อนกลับ)
   - วางเนื้อหาไฟล์ `firestore.rules` แล้วกด **Publish**
   - กฎใหม่ยังให้ spk-score-app ใช้งานได้เหมือนเดิม (ทุกคนอ่านได้ ผู้ที่ล็อกอินเขียนได้) และป้องกันข้อมูลของ SMART SPK (collection ที่ขึ้นต้นด้วย `ss_`)

### 2. เอาขึ้น GitHub Pages
1. สร้าง repository ชื่อ `smart-spk` (Public) ในบัญชี spk1234-aff
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์ `site` (จากไฟล์ smart-spk-site.zip) ขึ้นไป → Commit
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://spk1234-aff.github.io/smart-spk/`

### 3. เปิดใช้งานครั้งแรก
1. เปิดเว็บ ระบบจะขึ้นหน้า **ตั้งค่าระบบครั้งแรก** → สร้างบัญชีผู้ดูแลระบบ (ทำได้ครั้งเดียว)
2. ไปที่ **ผู้ดูแลระบบ(กิจการฯ)**
   - **ตั้งค่าทั่วไป / ชั้นเรียนและเวลาเรียน / เกณฑ์คะแนน** ตรวจค่าต่าง ๆ (จำนวนห้อง เวลาเรียน เวลาเริ่มนับสาย)
   - **ขึ้นภาคเรียนใหม่** ตั้งภาคเรียนปัจจุบัน (ค่าเริ่มต้น 2/2569)
   - **นำเข้า Excel / PDF** → นำเข้ารายชื่อนักเรียน (กดดาวน์โหลดแบบฟอร์มได้) แล้วนำเข้ารายชื่อครู
   - **ข้อมูลครูและบัญชีผู้ใช้** ตั้งห้องที่ปรึกษาและสิทธิ์
   - **ส่งออก Excel → รหัสเข้าระบบนักเรียน/ผู้ปกครอง** พิมพ์แจก

## การใช้งานบนมือถือ
- Android (Chrome): เปิดเว็บ → เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## การเชื่อมกับ spk-score-app
- ทุกครั้งที่มีการบันทึกมาสาย / ตัดคะแนน / แก้คะแนน ระบบจะปรับ `students/{เลขประจำตัว}` ของ spk-score-app ทันที
  `say` = จำนวนครั้งที่มาสาย, `khun` = คะแนนความประพฤติที่ถูกหัก
- รายชื่อนักเรียนที่นำเข้าใน SMART SPK จะอัปเดตชื่อ/ชั้น/ห้องใน `students` ด้วย
- ปิดการส่งข้อมูลได้ที่ ตั้งค่าทั่วไป

## หมายเหตุแพ็กเกจฟรี (Spark)
- แอดมินสร้างบัญชีครูได้ แต่ตั้งรหัสผ่านแทนครูไม่ได้ ถ้าใส่อีเมลจริงของครูไว้ จะกด "ส่งลิงก์ตั้งรหัสใหม่" ได้
- โควตาฟรีต่อวัน (ใช้ร่วมกับ spk-score-app): อ่าน 50,000 / เขียน 20,000 ครั้ง ระบบออกแบบให้ใช้น้อย (รายชื่อทั้งระดับอ่านครั้งเดียว, เช็คชื่อ 1 ห้อง = 1 เอกสาร)
- สร้างบัญชีจำนวนมากพร้อมกันอาจติดจำกัดของ Firebase (ประมาณ 100 บัญชีต่อชั่วโมงต่อเครือข่าย) ถ้าติด ให้รอแล้วนำเข้าส่วนที่เหลือใหม่

## พัฒนาต่อ
```bash
npm install
npm run dev        # ทดลองบนเครื่อง  (เปิด http://localhost:5173/?demo = โหมดทดลองด้วยข้อมูลจำลอง)
npm run build      # สร้างไฟล์เว็บลงโฟลเดอร์ docs/
```
โครงสร้างโค้ด: `src/backend.js` (Firebase/Memory) · `src/data.js` (โครงสร้างข้อมูล) · `src/core.js` (เมนู/การแสดงผล) · `src/views-*.js` (แต่ละหน้า)
